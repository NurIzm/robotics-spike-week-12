# По линии

Урок 12 кружка робототехники на LEGO SPIKE Prime: движение по чёрной линии с датчиком цвета. Собираем «Мобильную платформу 3» из приложения SPIKE, изучаем режим отражённого света и пишем программу, которая ведёт робота по краю линии.

## Что внутри

- стартовый экран с 3D-моделью «Мобильная платформа 3» на листе с чёрной линией;
- урок: что мы уже умеем, наш робот и его порты, как датчик видит линию (режим отражённого света), порог и калибровка, почему робот едет по краю линии, программа по шагам, настройка, плавный руль со звёздочкой, сборка и разборка, мини-тест;
- шесть анимированных историй о машинах, которые едут по линии или проводу: от первой тележки 1950-х до соревнований RoboCupJunior;
- программа: блоки как в приложении SPIKE слева, поле с роботом справа, шесть заданий:
  1. «Что видит датчик» — измерить белое, чёрное и границу, вписать порог;
  2. «Стоп на линии» — доехать до линии и остановиться;
  3. «Зигзаг по линии» — пройти круг по краю линии;
  4. «Быстрее!» — пройти трассу с крутым поворотом быстрее 24 секунд;
  5. «Плавный руль» — пропорциональный руль, виляние не больше 6;
  6. «Стоп на красном» — доехать по линии до красного поля и остановиться.

Робот на экране программы ездит по-настоящему: блоки движения крутят моторы C и D, датчик цвета в порту B читает картинку поля. Время в симуляторе своё, поэтому одна и та же программа едет одинаково на быстром и на медленном компьютере. Робота можно перетащить мышью на карте поля или прямо в 3D, стрелки ← и → поворачивают его.

Кнопка «Начать заново» на экране программы возвращает стартовые программы и стирает отметки. Она нужна перед следующим классом.

## Модель

«Мобильная платформа 3» из раздела «Модели» приложения SPIKE: сборка «Мобильная платформа» (34 шага) и сборка «датчик цвета» (4 шага). Порты: левое колесо C, правое колесо D, большой мотор с шестернёй E, датчик цвета B.

## Без интернета

Скачайте репозиторий (Code → Download ZIP), распакуйте и откройте `index.html` двойным кликом. Всё работает, только шрифты будут запасными.

## Как поменять

`index.html` собирается из исходников, вручную его не правьте. Экраны лежат в `src/views`, логика в `js`, стили в `css`, исходное задание в `src/SPEC.md`.

```bash
node src/build.js
```

Логику блоков проверяет `tests/vm-check.html`: откройте его в браузере, все строки должны быть PASS. Программы заданий лежат в `js/programs.js`, проверки и пороги заданий в начале `js/program.js`.
