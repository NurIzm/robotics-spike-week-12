# Қазақша нұсқа: терминдер мен стиль

The Kazakh copy lives in `kk/` (pages) and `src/kk/` (views, template). The Russian files are the source: when one changes,
change its copy in `kk/js/` or `src/kk/views/` the same way. `js/hero.js` has no text and is shared (`../js/hero.js`).

- `node src/build.js kk` stitches `src/kk/views/*.html` into `kk/index.html`. Safe any time.
- `node src/kk/check.js` lists text still identical to the Russian files or reading as Russian.
- `node src/kk/code-check.js` compares every `kk/js` file with its Russian source with comments and strings taken out. It must
  pass: only text changes (see «Code» below).

Week 10's copy (`../Week 10/kk`, `../Week 10/src/kk`) is the precedent, week 9's before it. This file keeps their rules and
replaces week 10's model words with this week's. Anything that is the same as last week (interface, block labels, colours,
quiz messages) takes last week's wording.

## Style

- Kazakh Cyrillic as in current school textbooks, with ә ғ қ ң ө ұ ү һ і where the word needs them. No Latin script except
  port letters, LEGO, SPIKE and names (Irwin Wu, NASA, OceanOne…).
- Speak to the student as «сен», like the Russian «ты»: «Бас», «Ұста», «Жібер», «Құрастыр», «Тексер». A Russian plural
  imperative to the class becomes a сендер form: «Обсудите» → «Талқылаңдар», «разберите» → «бөлшектеңдер», «не тяните» →
  «тартпаңдар».
- Short sentences for 10–14-year-olds. Buttons and labels stay short: at most about a third longer than the Russian.
- No plural after numbers: «үш саусақ», «екі тісті дөңгелек», «24 тіс», «алты кабель», «10 ньютон».
- Quotes «…», dash —, ranges with an en dash: «1–5». Decimal comma as in the Russian: «0,6 Н», «1,5 с».
- Facts, numbers and quiz answers stay exactly as in the Russian files. Quiz options keep their order (`ok` is an index).
- LEGO, SPIKE, SPIKE Prime stay as they are.
- The SPIKE app has no Kazakh, so students open it in Russian. Where the text names something in the app or a file, keep its
  Russian name in quotes: the instructions PDF «робо рука 3 моторами и 3 датчиками», the program «Manipulator 1».

## Grammar the copy depends on

- Ports: the Latin letter first, the Kazakh noun takes the ending. «A порты», «D портында», «F портына», «B портындағы
  датчик», «E моторы», «A саусағы», «A және C саусақтары». In templates: `${p} портында`, never `${p}-де`.
  Port lists join with «және»: «A және C», «A, C және E».
- Numbered things: a hyphenated ordinal, the ending on the noun. «3-модель», «11-апта», «2-кезең», «1-тапсырма»,
  «14-қадам», «1–5-қадамдар». In templates: `${n + 1}-кезең`.
- After a number, put a Kazakh noun so the ending lands on it: «270 позициясына», «80 позициясынан», «4 Н күшпен».
  If an ending must sit on a number or sign, use a hyphen and match how the number is read: «10 см-ден», «90°-қа»,
  «Робонавт 2-нің». Years: «2019 жылы».
- «X из N» → «X / N», or week 10's «${…}-кезең, барлығы ${…}».
- Question particle in prose: ма/ме after vowels and л, р, у, й; ба/бе after м, н, ң, з, ж; па/пе after other consonants
  («басылған ба?», «бүгілді ме?», «ұстай ма?»). Never after a closing quote.
- The izafet ending is replaced, not doubled, by a possessive: «қол басы» → «біздің қол басымыз», «бас бармақ» → «оның бас
  бармағы» (қ → ғ before a vowel), «күш датчигі» → «біздің күш датчигіміз».
- Kazakh has no gender. Where the Russian picks a form by gender or number (`obj.n ? 'выпало' : 'выпал'`, `'шаги' : 'шаг'`),
  keep the `?:` and write the right Kazakh in each branch, the same word in both if Kazakh needs no difference:
  `${obj.n ? 'түсіп қалды' : 'түсіп қалды'}`.

## Code: only text changes

`code-check.js` reads the code with every string literal and comment taken out, so:

- Change the text inside quotes and the text of HTML inside template literals. Comments are English and may stay as they are.
- Inside a template literal the `${…}` parts are code. Kazakh word order may move them, in any order, but each must stay
  exactly as written: `` `Датчик отпустили, а ${pl ? 'пальцы' : 'палец'} ${list} не разогнулся.` `` →
  `` `Датчикті жібердің, бірақ ${list} ${pl ? 'саусақтары' : 'саусағы'} жазылмады.` `` passes.
- Do not split a string with `+`, merge two strings, drop a `?:`, change quotes to a template with new `${…}`, or touch names.
- Strings that are code even though the check cannot see them: ids (`'cube'`, `'fingerA'`, `'thumb'`), object keys, CSS
  colours and class names, HTML tags and attributes other than `aria-label`, `title`, `alt`, `placeholder`, `data-*` values,
  STAGES `steps: '1–5'` (the lesson splits it at the dash), the write block's default `'Hello'` (week 10 kept it),
  file paths, `'kist-kk.'`. In a block menu `'нажата=pressed|…'` translate only the part before each `=`. In a block label keep
  every field spec as it is: `[PORT:multiple-port=D]`, `{OPTION:force}`, `(VALUE:8)`, `[OPTION:color=9]`, `%1`.
- The only code the copy changes is in `kk/js/blocks.js`, already done and listed in `code-check.js` (`ALLOW`), as week 10 did:
  `Blockly.ScratchMsgsKk`, the Kazakh fixes after `CLEAN_UP`, and the three palette names that wrap («Опера­торлар»,
  «Айныма­лылар», «Менің блоктарым»). The Russian line for «Допол­нительные моторы» is gone: that category's name comes from
  the TOOLBOX row, «Қосымша моторлар». Media path `'../vendor/media/'` is set.

## The model

The model is «Қол басы» (кисть: the hand below the wrist). Why: it is the Kazakh anatomy word for кисть (Kazakh Wikipedia «Қол»:
«саусақтар орналасқан мүшесі қол басы деп аталады», with its 27 bones of білезік, алақан and саусақтар), week 10's copy
already used it (кисть → қол басы, кисть-протез → қол басының протезі), and it keeps the hand apart from «қол» (рука), which the
series uses in «Робот-қол». «Қол ұшы» is not the hand: it reads as fingertips or the idiom «қол ұшын беру» (to help).
On the start screen «ҚОЛ БАСЫ» is 1.53 times as wide as «КИСТЬ». The template's `.hero { --title: min(8.2vw, 14.4vh); }`
gives it the Russian title's share of the width (about 55 % at 400–1920 px).

students can find the block.
